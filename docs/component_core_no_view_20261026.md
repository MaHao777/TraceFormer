## 实验定义

|ID|相对Full的唯一结构替换|
|---|---|
|Full|4 Query Tokenizer、3层双向多锥编码器、Event Decoder与多尺度精修Head|
|M1|事件编码器输出直接按块求均值，删除Query聚合及融合，不增加补偿MLP|
|M2|Token投影删除7项块统计输入及对应参数，保留Query聚合与位置编码|
|M3|三层仅保留原有LayerNorm、FFN、残差和最终归一化|
|M4|基础Decoder与精修Head均删除六维局部特征的直连参数，保留事件与几何对齐|
|M5|严格只保留原有8×8×50ms分支、事件残差分类与原有辅助监督|
|C1|中心Token查询26邻接中实际占用的Token，4头局部点积注意力|
|C2|保留三尺度、双向六摘要和Center Attention，固定窗口为(6,2)/(3,4)/(1,8)|
|C3|严格保留中间锥(4,4)过去/未来两个摘要|
|C4|保留三个尺度，只计算过去方向的三个摘要|
|C5|保留六锥加权池化与槽位编码，仅替换成有效摘要均值和线性投影|

所有(R,H)以Token网格为单位，Full锥尺度为(8,2)/(4,4)/(2,8)。C1含同时间块空间邻居，去掉中心，不用Top-K或远邻补齐，空邻域输出为零。

## 固定协议与资源门槛

seed37、99训练/24验证/24测试、24轮、CPU FP32、8线程、AdamW学习率0.0007及权重衰减0.0002。其余配置继承Full，保留原有损失、密集序列加权、采样与学习率调度。公共层配对初始化，替换层构造不推进训练RNG；训练文件顺序和采样由原有独立随机数生成器控制。

冻结源码、配置和数据清单后，对旧运行源码和新Full适配路径使用同一个检查点，逐事件核对24个验证序列的logits、Token坐标与事件映射完全相同。所有组在`train_094/train_096`上以真实训练损失做完整前反向预检。

C1与Full先预热一次再测三次，中位前反向耗时不得超过同文件Full两倍，峰值RSS不得超过物理RAM的70%。26邻接超限或预检子进程失败时，统一改为±x/±y/±t六邻接并重新检查；仍失败则停止并保留报告。不得参考验证或测试精度选择邻域。其他变体均检查两条完整序列的有限梯度和内存门槛。

## 输出与恢复

- `implementation_checks.json`：实现测试及对应源码指纹；源码改变后必须重新验证。
- `baseline_audit.json`、`full_equivalence.json`：Full复用的验收与精确输出等价证明。
- `suite.json`、`source_hashes.json`、`source/`：冻结十组定义、配置、数据身份与执行源码。
- `preflight/`、`resource_gate.json`：全部资源预检与C1最终邻接选择。
- `seed37/<ID>/attempt_*/`：训练曲线、最佳权重、逐轮恢复状态、训练指标与独立验证结果。
- `test/<ID>/`：原顺序概率、掩码、源哈希、独立重评及另一套官方计数核验。
- `benchmark/<ID>.json`：同设备预热后三次推理、进程峰值内存；C2另记录全验证集窗口交并统计，诊断排除在计时和峰值内存测量之外。
- `results.md`、`results.json`：两张共用Full的结果表、AP、阈值与相对Full的差值。
- `completion_audit.json`：11组结果完成后的文件哈希审计。

只有验证集选择epoch和阈值，测试集使用冻结阈值。测试结果已经有历史查看记录，不声称从未接触测试集。聚合采用全量计数，不排除困难序列。M3仍有Head上下文、C4整网非因果、C3/M5同时减少参数；不将单种子结果解释为稳定性或统计显著性。

意外中断后再次运行同一入口，优先检查仍在运行的子进程，使用冻结源码及原训练状态恢复；已完成的训练不重跑，已有测试概率仍需重新评分。明确标为`failed`的阶段保留现场，先定位原因再恢复，不能覆盖重启或跳过验收。全部完成后自动任务汇报结果并暂停。
