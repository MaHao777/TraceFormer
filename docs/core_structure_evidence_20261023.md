# 核心提分结构与可复现实验（2026-10-23）

## 已找到的结构

当前证据最强的结构是**验证引导、具有最少观测支持要求的轨迹条件恢复，与高置信直通分支的并集**。

它把两种决策分开：验证器直接保留可靠事件；另一分支将高置信事件连成轨迹，要求至少 8 个关联观测节点，再在轨迹附近接受较低置信事件。这里的 8 是节点数，不是连续 8 帧，也不是首尾时间差。直接分支补充轨迹没有覆盖的事件。

这是一项系统决策结构的证据。现有实验没有找出能够独立证明优于局部注意力的新神经注意力结构，不能将完整系统的收益归给多锥摘要。

同帧空间对照保留原始热点屏蔽、种子组件、空间区域、低分阈值、fallback 和每中心最少事件数，只把每个种子节点当作单帧支持，去掉跨帧关联、节点数门槛、插值和延伸。这是整个时间恢复机制的复合消融。

## 可以写进论文的论证

1. **不仅是降低阈值。** 完整结构比验证选定阈值基线提高测试 Score 0.014500；少 257 个 TP，却少 1,318 个 FP，多检出 67 个目标帧。收益来自更有选择的时空接受条件，不能解释为简单增加正预测。
2. **不仅是同帧空间扩张。** 完整结构比匹配的同帧恢复提高 Score 0.007604，增加 130 个检出目标帧；同时增加 262 个 TP 和 133 个 FP。它改善弱帧覆盖，并非各项指标全面占优。
3. **关联观测支持抑制背景。** 取消至少 8 个关联节点的要求后，额外得到 151 个 TP 和 26 个目标帧，却增加 2,591 个 FP，Score 下降 0.014897。门槛收益在高密度序列更明显，不能声称所有场景都改善。
4. **时序是恢复分支实际使用的信息。** 固定 seed37 置换 50 ms 帧号，保持帧内事件、空间与分数对应，Score 下降 0.020462。此实验只干预下游轨迹，神经和树分数仍含原始时序信息。
5. **端点延伸不是稳定提分核心。** 去掉延伸，测试 Score 反而增加 0.000929，验证 Score 降低 0.002202。保留两者结果，不依据测试更改生产配置。

另有完整的 10,000 次序列配对重采样和逐序列胜负统计：完整结构相对阈值基线的条件 95% 区间为 [0.002525, 0.028754]，相对同帧恢复为 [0.001767, 0.014254]。这只描述固定模型在当前分区的序列组成不确定性，不代表训练种子稳定性。

## 必须保留的反证与边界

- 已完成的 A0–A3 单种子、24 轮实验：直接局部注意力 A0 测试 Score 0.907705，高于多锥摘要 A3 的 0.906259。A3 对单锥有提升，同时改变范围、尺度和摘要槽位，不能独立归因。
- 旧多查询池化、Sparse 和精修结果来自不同历史主干/协议，不混入当前结构表。精修的小幅正收益也未证明多尺度本身是原因。
- 新实验是**冻结系统推理干预，不是从头重训消融**。模型和阈值保持冻结，但测试集以前已被查看，因此属于探索性归因，不是新的未见测试确认研究。
- 当前主模型由用户指定；原自动 Fa 门槛失败记录保留。此次没有修改生产模型或重新宣称通过门槛。
