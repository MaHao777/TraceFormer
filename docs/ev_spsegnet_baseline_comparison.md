# 与 EV-SpSegNet 基线的边界比较

EV-SpSegNet 可作为后续实现和实验对照的基线；本仓库目前不复制或实现其网络、稀疏卷积、HAIS、自定义 CUDA 或数据读取逻辑。HUAV 计划的主干是层次化局部窗口 Transformer 与 U 型解码器，使用密集体素契约 `[B,32,260,346] -> [B,16,260,346]`，而不是在 Phase 1 中锁定任一基线的内部算子。

所有可比较的实验都应统一 250 ms 窗、125 ms 步长、16 时间 bin、双极性输入，以及事件级重叠 logit 聚合和 Codebench 五列提交约束。已记录训练集统计为 99 条序列、9,324,544 个事件、2.939790% 正事件；250 ms/16 bin 下约 0.0025% 标签冲突。官方排名指标尚待确认，故当前不主张任何排名结论。
