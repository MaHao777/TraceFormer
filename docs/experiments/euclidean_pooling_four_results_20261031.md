# 欧氏过去锥四组实验回传分析（2026-10-31）

**E3（单核池化＋三尺度中心锚定欧氏过去锥）是本轮验证与测试Score最高的结构。** 相对E0，验证增加0.009452401，测试增加0.006930087；单核与中心摘要的组合呈正交互。小锥局部注意力明显更快；E1的召回增长被假警增长抵消，测试净收益仅0.000895374。

这些结论限定为seed37、24轮、当前四套设计；不是跨种子显著性证明，也不代表欧氏锥全面优于方锥。

## 回传与独立核验

- `remote_result/results/full`的592个清单文件SHA256全部通过；79个Python源码文件、冻结包清单及公共初值审计与交付一致。
- 本地99训练／24验证／24测试文件哈希全部匹配。四组均独立完成24轮，每轮99个优化步骤，未记录非有限梯度步骤，没有复用旧权重。
- 严格加载四组最佳权重与版本5契约；最佳epoch与history中的验证最高Score相符。
- 重新读取192份逐事件概率和对应掩码，校验行对齐、概率范围及冻结验证阈值；用本地原始标注重新计算每文件与全局计数及AP，全部复现。
- 云端四组训练前及训练后CPU/CUDA输出与梯度对照通过，train_094/train_096完整训练步骤通过。此处没有在本地重新运行完整神经前向。

环境为RTX 4090、PyTorch 2.10.0+cu128、CUDA 12.8、FP32、8辅助线程，TF32关闭。网络保留Event Decoder及多尺度精修Head，不使用外部后处理。局部为(2,2)，中心为(8,2)/(4,4)/(2,8)，均只读过去；注意力比较同时改变邻域范围和交互方式。单核为depthwise 3×3卷积＋GELU。
