## 计时范围与环境

- 网络使用冻结的 schema-7 prefix-cone，189,900 个神经网络参数，包含 Sparse 路径和 refinement。
- 单模型：从内存中的事件输入准备开始，包含上传、Sparse 构造、完整网络前向、sigmoid/固定阈值和掩码回传；不构造后处理缓存。
- 完整管线：在同一网络基础上，增加 Token FP16 往返量化、112 维事件特征、small/large 两套树、CPU 主轨迹和直接分支，最终输出两分支并集。
- 以上都排除 NPZ 读取/解压、预取源几何数组、模型加载、预测压缩写盘、评分和数值检查。
- batch=1，不裁剪事件数；每个模式先用当前分区最大文件预热一次，再按文件顺序运行完整三轮。主计时只在首尾显式 CUDA 同步。
- RTX 3090 24 GiB；Intel Xeon Gold 6330，容器 CPU 配额为 14 核，主计时使用 8 线程。容器内存上限 60 GiB。
- Python 3.12.3，PyTorch 2.8.0+cu128，CUDA build 12.8，驱动 595.71.05，LightGBM 4.7.0，Numba 0.68.0，numba-cuda 0.30.4。
- FP32，TF32 关闭，确定性算法开启；GPU 计算网络、特征和树，CPU 执行轨迹。没有在计时进程旁并行运行其他本次任务。

## 额外一轮的模块拆分

阶段分析在三轮主计时之后另跑一轮，并在模块边界同步。它用于定位开销，不参与上表统计。

| 该轮合计 | 1247.546 |

在单模型的这轮阶段分析中，纯 `model.forward` 为 **479.676 ms/文件**；
含输入准备、Sparse 和传输后的合计为 519.589 ms/文件。
完整管线中的纯 `model.forward` 为 484.765 ms/文件，已经包含在 540.895 ms 内，不可重复相加。
这是一轮带同步的诊断测量，正式性能比较使用前三轮的 547.713 / 1255.058 ms。
