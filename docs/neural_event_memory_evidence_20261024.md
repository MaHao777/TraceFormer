# 神经时间记忆结构：完整证据与结论（2026-10-24）

全部训练、原始验证/测试推理、独立评分和六个完整神经图的计时已完成。最终论文编译与版面检查单独记入论文 evidence 目录。

## 有效结构与结论边界

有效的探索性结构是 **G：Token 语义条件化的时间记忆融合**。原始事件的同像素、同/异极性、严格过去/未来四个间隔，经1/10/50 ms指数基底得到 memory12，投影为16维；父Token的64维特征产生16维sigmoid门控，两者逐通道相乘后与token64、local6共同进入MLP。旧神经预测、LightGBM和轨迹均不进入这张图。

G在三个head seeds的验证和测试Score中均高于原始重训读出B，在单seed末层适应后也保持Score优势。该判断来自完整锁定矩阵，**不是预先选定候选的确认成功**：测试前按冻结验证均值提名的是C，C的测试Score优势没有成立。保留 `candidate_selection.json` 和 `evaluation_lock.json` 的原始C记录，事后解释单独放在 `interpretation_after_evaluation.json`。

## 机制检查及未成立的解释

C固定权重的验证敏感性：记忆置零会下降，但Token内均值与联合置乱不降低Score。查看完整测试矩阵后又对G作了同样的**验证集**事后检查：冻结G原始/均值/置乱/置零Score为0.898697672 / 0.900087392 / 0.899138678 / 0.893784091，末层适应组同样如此。

结论是时间记忆信息被使用，不能归因为精细事件对应关系的必要性。这些干预不重训、不改阈值，有分布偏移边界，不代替B/C/U/G训练对照。没有用均值干预再挑测试模型。时间表面、局部上下文拼接和条件调制都有先例，不声称其算子首创。

## 原始图复评和数值实现修正

16模型×24验证序列的384对raw/cached logits逐位相同、最大误差0，阈值掩码全部相同。验证和测试全部保存掩码由不同PID独立评分，全局和逐文件计数均一致；所有测试阈值保持验证所选值。

初次验证因首文件1.049e-5的logit差异中止，尚未推理新测试模型。受控复现确定：在外层inference_mode内构造模型会产生inference参数，与训练/缓存普通参数的CPU数值结果不同。评估改为no_grad构造普通参数，实际特征提取仍用原inference_mode。未改动缓存、权重、阈值或1e-6容差。失败日志、受控复现和384对通过记录保存在 `diagnostics/evaluation_numerics.json`。新增两项回归测试通过；此前完整仓库357 passed、2 skipped。
