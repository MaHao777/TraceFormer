# 原有神经网络：结构理解与收益定位

本次对象是冻结主模型 `outputs/main_model/best.pt` 与其原字节配置，不包含新增记忆解码器，也不以外部树模型或轨迹收益解释神经结构。当前权重为 seed37、24轮、从头联合训练；参数189,900。目标仍是定位原结构的收益，尚未完成重训确认。

## 实际计算路径

1. **事件变为块表示，43,008参数。** 原始 `(x,y,t,p)` 按8×8像素、125ms分块，只建立非空Token。每个事件的六维局部特征为块内x/y/t、极性、相对序列极性的差、序列平均极性。逐事件MLP之后，四个共享学习查询分别在块内池化，再与七维统计和绝对块位置拼接，投影为64维Token。
2. **三个残差编码层，114,179参数。** 先对Token做LayerNorm。邻居Token各自生成64维Value和一个正权重；每个中心分别读取三种空间/时间支持域的过去与未来，共六个摘要。中心对这六个摘要做四头注意力，随后是残差和逐Token FFN。
3. **Sparse视图残差，17,750参数。** 仅在事件数≥300,000、最大极性比例≤0.65的流上生成1.5倍阈值子流。共享Tokenizer/编码器，按原块坐标对齐，将门控残差加到Full Token。仍按Full事件索引输出。当前24验证序列只有val_023触发。
4. **原事件解码器，6,785参数。** 将64维父Token与六维事件局部特征拼接，经过70→64→32→1的MLP输出基础logit。这里没有额外的事件时序记忆模块。
5. **原有多尺度残差精修，8,178参数。** 复用父Token、事件局部特征与基础logit，分别按2×2×10ms、4×4×25ms、8×8×50ms聚合mean/max/log-count，再读同空间cell的前/当前/后时间格，给每个原始事件补一个logit残差。它属于神经网络，参与当前联合训练。

最值得区分的两个运算：

\[
a_j=\operatorname{sigmoid}(w^T\operatorname{LN}(h_j)+b)+10^{-4},\qquad
s_{i,k}=\frac{\sum_{j\in\mathcal N_{i,k}}a_jv_j}{\sum_{j\in\mathcal N_{i,k}}a_j}.
\]

这是**摘要内部、与中心查询无关的邻居权重**；之后才是中心查询对六个摘要的Q/K/V注意力。它们不是同一个注意力操作，不能混称后再做消融。

三组支持域`(R,D)=(8,2)/(4,4)/(2,8)`，时间距离d处的半径为`floor(R*d/D)`；双向、排除同时间块、读取全部占用邻居。宽短域覆盖到64像素/250ms，中域32像素/500ms，窄长域16像素/1000ms。前缀和仅精确实现加权区域求和，本身不改变数学预测函数。

配置中的旧`cone_heads/layer_time_scales/max_neighbors_per_cone/direction_dropout`由配置规范化移除，不参与当前前向；当前模型没有这些旧字段暗示的Top-K邻居或逐对运动偏置。

## 训练与归因的关系

当前总损失还包括Focal、Dice、目标帧召回、全事件假警像素约束、精修cell辅助监督，以及触发Sparse时的辅助项。正样本全部保留，负样本最多12:1，其中一半为hard negatives。结构与专属监督要分别控制；旧的分阶段添加结果不能直接当作当前联合训练模块的独立贡献。

均匀中心注意力的实现与保留V/输出投影、将Q/K投影置零的独立参考核对，最大绝对误差1.79e-7。它与“摘要内部邻居权重均匀”是两种不同操作。

进一步只观测正常前向权重，GT在前向结束后才用于分组，得到583,131个Full Token：含目标Token仅占0.9327%。第2层纯背景Token权重均值0.11809、中位数0.05469；混合Token均值0.61976、中位数0.84827；纯目标Token均值0.64992、中位数0.86713。含目标Token占该层总权重质量4.8377%，高于其数量占比。详细统计及实际执行源码见该目录的`weight_statistics.json`和`inspect_weights.py`。

这些观察支持一个具体的**机制假设**：第1层交互产生初步上下文表示，第2层学习的邻居权重使少数含目标Token在后续摘要中更突出，减少背景Token对目标上下文的稀释。它是对现有运算的解释，不是新加入的结构或已完成的独立收益证明。

尤其不能把0.92594→0.62396宣称成第2层加权带来30个AP点。第2层消息完全关闭时AP仍有0.89283，说明错误聚合后的消息比不接收消息更具破坏性；当前权重还与其他模块协同适应。正式对照必须同时保留**学习加权、均匀加权、关闭消息**三种条件，不能只选择掉分最大的破坏实验。

## 最小确认实验（本轮已执行）

以下计划已按共同短程预算执行，详见[原读出恢复结果](original_readout_recovery_20261024.md)。99训练/24验证，seed37，共同2轮，每组198次更新；原编码器表示冻结，只重置并训练原有14,963参数读出。包含缓存、加载、门槛、训练、验证阈值选择及原始网络复评，共14.50分钟。

恢复后学习加权/均匀加权/关闭第2层消息的AP为0.905816/0.882453/0.876363，验证选择阈值下Score为0.888884/0.880657/0.879104。学习加权相对均匀的AP差由30.199个百分点缩小到2.336个百分点；同预算仍有优势，但三组末轮都在提高，学习加权组尚未达到原训练读出的AP，因此不能将此结果当作充分收敛的结构增益。

这轮排查了部分原读出适应问题；冻结的编码器后续层仍与原学习权重协同适应。候选结构依然是学习加权的跨块摘要，正式确认应训练受影响编码层与原读出，保留三组共同预算；不能继续沿用破坏实验中的30个AP点作论文提分证据。
