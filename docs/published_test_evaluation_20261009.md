## 核验

- 主网络 169,632 参数、schema 5；参考网络 151,882 参数、schema 4；两个 LightGBM 与轨迹规则保持原发布版本。模型、原始配置、源码和阈值与既有发布报告一致。
- 神经推理 CPU FP32、14 线程、PyTorch 2.11.0+cpu，阈值 0.38749998807907104。测试模式不调用阈值搜索，推理序列标签与目标 ID 清零。
- 最大序列 test_023（620,440 events）的原始标签/清零标签概率逐位相同，最大绝对差为 0，包含实际激活的 sparse 路由。
- 四阶段全部保存原事件顺序的二值掩码；独立进程读取原始 ev 数组再次计分，阶段报告与独立报告一致。神经指标与另一计数实现一致。
- 输入数据、模型、源码和全部预测记录 SHA-256；七个后处理/评分源码文件与先前发布源码完全相同。
