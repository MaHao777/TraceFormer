# 近期消融综合对比（2026-10-29）

本次以新回传的 `remote_result/results/full` 六组正式 GPU 结果为最新证据，串联 10/21 中心注意力、10/26 无稀疏视图模块/架构、10/27 A/B 和 10/28 均值过去锥实验。10/23 完整系统后处理消融单列。10/25 已撤回的旧含视图消融不并入主表；固定权重干预与两轮读出恢复只作为机制旁证。

最主要的结果：**空间卷积池化在本轮两类编码器中都优于对应的纯均值基线；摘要编码器的验证最高为 S1，测试最高为 S2。局部编码器参数更少、推理更快，但对应配对 Score 更低。** 这些是 seed37 的观察，尚不能称为跨种子稳定收益。

## 口径与可比性

- 主体是纯神经网络，包括网络内部的 Event Decoder 和多尺度精修 Head；这些组没有 LightGBM、轨迹恢复等外部后处理。
- 99 train / 24 val / 24 test，seed37，24轮。验证集选择 epoch 和工作阈值，测试沿用该阈值，不按测试重选。不同模型允许选择不同验证阈值。
- Score = 0.2 IoU + 0.1 SegAcc + 0.4 Pd + 0.3 exp(-10000 Fa)。所有主表使用全量整数计数，不能平均逐文件 Score 代替。
- SegAcc 为目标事件召回率；Pd 为官方目标帧检出率；Fa 是单位像素帧的背景假警连通分量率。**Fa 与逐事件 FP 率不同。** AP 是逐事件概率排序指标。
- 最新六组为同一 RTX 4090、PyTorch 2.10.0+cu128、CUDA 12.8、FP32；旧 M/C、A/B 和 A0–A3 为 CPU FP32。跨实验系列的精度可作描述性参照，不能把 CPU/GPU、基线和模块同时变化的差值解释成某一个模块的因果收益；不同设备的毫秒数不直接比较。
- C1 是含同时间块空间邻居的 26 邻接；最新 L 组是排除当前时间的过去两块 34 候选格点。它们不是同一局部注意力对照。

### 配对比较与收益来源

- **单核卷积有一致的组内收益。** S1−S0：验证 +0.010286、测试 +0.006493；L1−L0：验证 +0.007580、测试 +0.006083。支持本次空间处理方向，但不是跨种子稳定性证明。
- **双核不总优于单核。** S2−S1：验证 −0.000328、测试 +0.002595；L2−L1：验证 +0.000064、测试 −0.001447。没有“核越多越好”的证据。
- **三尺度摘要在最新配对中 Score 更高。** S0−L0：验证 +0.002780、测试 +0.001871；S1−L1：验证 +0.005486、测试 +0.002281；S2−L2：验证 +0.005094、测试 +0.006322。结论限定为本次支持域和实现，不能推成摘要注意力普遍优于局部注意力。
- **L1 的概率排序最好，但官方工作点不是最好。** L1 验证 AP 95.611%、测试 AP 96.175%，均为六组最高；其测试 Score 0.919507 低于 S1/S2。AP 不约束官方目标帧 Pd、假警分量和验证阈值迁移，不能拿最高 AP 代替最高 Score。
- 单核交互差值 `(L1−L0)−(S1−S0)` 在验证/测试为 −0.002706/−0.000409，没有正向叠加协同证据；单种子差值也不作统计显著性解释。

S2 相对 S0 的测试 Score +0.009087，可按公式拆为：IoU 项 +0.004795、SegAcc 项 +0.001071、Pd 项 +0.002219、假警项 +0.001002。它在这四项均改善，主要贡献来自分割 IoU。

## 综合判断与下一步优先级

1. **结构保留方向：** 七项块统计、编码器跨Token消息和低成本事件特征直连应优先保留。四Query池化没有显示优势；纯均值是有竞争力的简化基线，轻量空间卷积是新一轮最有支持的改进方向。
2. **候选的选择口径：** 若按本轮既定验证Score选择，选择S1（0.913655）；S2的测试0.924382最高，是值得保留的对照候选，但不能因为看过测试后反过来称其为验证选定赢家。S1/S2的验证差0.000328很小，需共同多种子训练核实。
3. **效率选择：** L0是最新六组最省平均前向的模型；L1在减少约9%参数的同时保留较强AP。是否接受其Score损失取决于运行目标。不存在一组同时在Score、AP、耗时、参数和显存上全面最优。
4. **不优先继续堆复杂度：** 双核并非各组都优于单核；六层无门控B更大且更差；四Query未优于纯均值。当前证据更适合验证轻量空间处理，而不是据参数增长推定性能提升。
5. **论文归因：** 最新S/L同时改变邻域和交互，卷积同时引入非线性；单种子与已反复查看的测试集不能支持统计显著、盲测或普遍优越性的表述。历史冻结权重路径破坏的大幅掉分只证明已训练网络依赖该路径，不能替代从头训练消融。短时恢复也不是充分收敛证据。
6. **下一步具体实验：** 首先用一致协议复核S0/S1/S2的多种子结果；再匹配池化、过去方向和支持域研究S/L差异。如要评价最新模型的完整系统分数，需要对新特征/概率重新训练并独立验证兼容的后处理，不能复用旧树成绩外推。本次只分析现有产物，没有启动训练或修改发布模型。
