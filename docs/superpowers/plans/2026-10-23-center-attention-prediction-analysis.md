# 四组注意力测试预测分析计划

> 本次在当前本地仓库内顺序执行，不使用 worktree 或新增训练。

**Goal:** 从已有逐事件概率、掩码和原始标注，解释四组测试差异的来源。

**Architecture:** 单个离线分析脚本读取冻结实验目录，将全局指标拆成事件、目标帧和虚警连通分量，并输出逐序列统计、预测差异图与报告。原有阈值、权重和报告保持不变。

**Tech Stack:** Python、NumPy、SciPy、PyTorch、scikit-learn、Matplotlib。
